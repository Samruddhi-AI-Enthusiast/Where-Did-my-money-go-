💸 Where Did My Money Go?

Where Did My Money Go? is a simple beginner-friendly Python project designed to help students track and understand their monthly expenses.

The program takes a monthly budget and expenses such as food, travel, shopping, and entertainment. It then calculates the total amount spent, identifies the biggest expense, shows the percentage spent in each category, and displays the remaining budget.

✨ Features

- 💰 Enter your monthly budget
- 🧾 Record expenses by category
- 📊 Calculate total spending
- 🔥 Identify the biggest expense
- 📈 Display expense percentages
- 💵 Calculate remaining budget
- ⚠️ Get a warning when the budget is exceeded

🛠️ Technologies Used

- Python
- Python Dictionaries
- Functions
- User Input
- Basic Mathematical Operations

▶️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python app.py

5. Enter your monthly budget and expenses when asked.
